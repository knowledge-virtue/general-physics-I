# general-physics-I
I will teach special relativity in six 45-minute classes；consequently, lectures 8, 16, and 20 will be omitted from the syllabus. Additionally, supplementary lecture notes covering Keplerian motion, sound waves, and minimal work are available as alternative topics. 
The 习题 and 答案 folders contain the exercises and their corresponding reference solutions. You can select 10 problems from any single PDF file in the '习题' folder as homework, which must be completed in handwritten format. The teaching assistant will record your homework grades toward your usual performance grade.
